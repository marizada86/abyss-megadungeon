# Agentes nativos da Atena — biblioteca r1

Esta biblioteca integra a distribuição 0.5.0. Os oito papéis estão no [catálogo](catalog.json), com brief e procedimento em cada arquivo. Seu conteúdo é DRAFT r1 com implementação autorizada no PLAN-022 r1; isso não promove regras do projeto a CANON. Origem: responsabilidades do catálogo Marizverso r4, separadas de qualquer conhecimento pessoal. O perfil pessoal permanece opcional; não é necessário adotá-lo para usar estes papéis.

Leia o [contrato](CONTRACT.md), identifique a necessidade e abra somente as instruções pertinentes:

| Necessidade | Papel e procedimento |
| --- | --- |
| Plano, revisão ADD, integração de entregas | [Atena](atena.md) |
| Aplicações, código, contratos e documentação | [Indiano](indiano.md) |
| Pesquisa ou curadoria de fontes | [Odin](odin.md) |
| Design e implementação de jogos | [Miyazaki](miyazaki.md) |
| Arte de jogos e assets | [Prometeus](prometeus.md) |
| HQ, storyboard e composição de páginas | [Stanley](stanley.md) |
| Campanhas e sessões de RPG | [Zeus](zeus.md) |
| Lore, fontes narrativas e continuidade | [Tolkien](tolkien.md) |

Uma consulta simples pode ser resolvida pela Atena. Quando houver uma necessidade de domínio, consultar o procedimento correspondente e declarar a participação real. O usuário pode pedir um papel pelo nome. Uma troca de papel nesta sessão é execução sequencial pelo mesmo assistente; não é uma revisão independente. Instalação não inicia processos, instala ferramentas nem autoriza delegação. Se faltar capacidade para uma entrega, produzir os insumos textuais possíveis e indicar a pendência concreta.

Após instalação/atualização aprovada, o AGENTS.md do projeto aponta para esta biblioteca no snapshot versionado. `atena-add agents <projeto>` lista a biblioteca efetivamente instalada; `status --details` distingue biblioteca, integridade e reconhecimento do cliente. Nenhuma instalação anterior muda sem atualização. Em outro PC, usar o mesmo pacote revisado e adotar no projeto; não há sincronização automática de memória. Em cloud/outro cliente, confirmar que as instruções do projeto foram realmente carregadas.
